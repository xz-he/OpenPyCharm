# 导入 PyCharm 配置

在 PyCharm 中通过 **File → Manage IDE Settings → Export Settings** 导出 `settings.zip`。无需解压，也无需先转换为 JSON。

在 OpenPyCharm 中有两个入口：

1. 欢迎页 → 自定义 → **导入 PyCharm 配置…**。
2. 文件 → 管理 IDE 设置 → **导入设置…**，选择 `.zip`；也可在查找操作中搜索 `PyCharm`。

选择文件后，预览窗口列出可导入的设置类别和未映射项目。点“导入”才写入设置；取消不会修改配置。导入按导出包中明确保存的选项合并，未导出的 PyCharm 默认值不会推断或覆盖 OpenPyCharm 的现有值。

## 支持范围

| 配置 | 当前支持 |
| --- | --- |
| 常规设置 | 退出确认、重新打开项目、打开项目方式、空闲保存 |
| 外观 | 已支持的界面语言、工具窗口名称、部分编辑器标签页选项、界面字体；内置深浅色主题映射 |
| 编辑器 | 字体、字号、行距、连字、行号、空白字符、缩进线、软换行、光标和部分补全/输入选项 |
| 编辑器配色 | 导入 `.icls`，选择当前方案；复用已有颜色转换器，未支持属性列入报告；基础主题使用 OpenPyCharm 内置主题，不保证像素级一致 |
| 快捷键 | 内置 Windows/macOS/VS Code/Eclipse 预设；基于已支持预设的自定义键盘快捷键、双段快捷键、显式取消绑定；仅转换已映射的动作 |
| 代码风格 | 当前代码风格中的全局行宽/缩进/换行符及 Python 的缩进、制表符和行宽 |
| 终端 | 字体、字号、行距、响铃、选择即复制、关闭行为及 Option/Meta 等部分交互选项 |

不导入 PyCharm 插件、账号、凭据、信任列表、解释器登记、远程连接、数据库驱动、窗口位置、检查配置和其他未映射选项。导出包中的插件列表不会安装插件。多个解释器登记不代表一个可直接使用的当前项目解释器，请在语言设置中选择实际 Python 路径。

未知动作、鼠标快捷键、依赖其他自定义键位方案的继承关系暂不转换，在预览中列出。项目级设置仍优先于全局设置。

## 备份与恢复

每次导入前，在应用配置目录写入独立的 `settings-before-pycharm-*.toml` 文件；写入或校验失败时不修改原设置。成功窗口显示备份的绝对路径。

如需恢复：关闭 OpenPyCharm，将该备份复制为同目录下的 `settings.toml`，然后重新打开。建议保留当前 `settings.toml` 的副本。原 PyCharm 压缩包与配置目录始终只读。

压缩包不会解压到磁盘；路径、文件数量和大小有边界检查，XML 不允许 DTD。无有效导出标记的 ZIP 或损坏的受支持 XML 文件会被拒绝。
